## 🔓 Open-Source GitHub Projects

*Sorted by GitHub_Stars_Count (Descending)* 🌟

- **[Docusaurus](https://github.com/facebook/docusaurus)** [![Stars](https://img.shields.io/github/stars/facebook/docusaurus?style=social&color=white)](https://github.com/facebook/docusaurus/stargazers)  
  **Static site generator for documentation**, MIT licensed. **66,430+ Stars**. React-based static site generator with MDX support, versioning, i18n, and built-in search. Used by React Native, Meta, and thousands of tech teams. 🦖

- **[Outline](https://github.com/outline/outline)** [![Stars](https://img.shields.io/github/stars/outline/outline?style=social&color=white)](https://github.com/outline/outline/stargazers)  
  **Collaborative team knowledge base & workspace**, BSL-1.1 licensed. **40,828+ Stars**. Modern Markdown wiki with real-time collaboration, Slack integration, and fast search. 🏢

- **[Slate](https://github.com/slatedocs/slate)** [![Stars](https://img.shields.io/github/stars/slatedocs/slate?style=social&color=white)](https://github.com/slatedocs/slate/stargazers)  
  **Clean multi-panel API documentation generator**, Apache-2.0 licensed. **36,022+ Stars**. Clean three-panel API documentation layout inspired by Stripe and PayPal docs. 📜

- **[Backstage](https://github.com/backstage/backstage)** [![Stars](https://img.shields.io/github/stars/backstage/backstage?style=social&color=white)](https://github.com/backstage/backstage/stargazers)  
  **Open platform for building developer portals**, Apache-2.0 licensed. **34,570+ Stars**. Created by Spotify for managing microservices, TechDocs, and software templates. 🎪

- **[Docsify](https://github.com/docsifyjs/docsify)** [![Stars](https://img.shields.io/github/stars/docsifyjs/docsify?style=social&color=white)](https://github.com/docsifyjs/docsify/stargazers)  
  **Magical documentation site generator**, MIT licensed. **31,538+ Stars**. Dynamic client-side Markdown rendering without static HTML build steps. 🪄

- **[Swagger UI](https://github.com/swagger-api/swagger-ui)** [![Stars](https://img.shields.io/github/stars/swagger-api/swagger-ui?style=social&color=white)](https://github.com/swagger-api/swagger-ui/stargazers)  
  **Interactive OpenAPI/Swagger API documentation**, Apache-2.0 licensed. **29,029+ Stars**. The industry-standard web component to render OpenAPI specifications with interactive API testing. 🎯

- **[Wiki.js](https://github.com/requarks/wiki)** [![Stars](https://img.shields.io/github/stars/requarks/wiki?style=social&color=white)](https://github.com/requarks/wiki/stargazers)  
  **Powerful open-source wiki app**, AGPL-3.0 licensed. **29,015+ Stars**. Node.js wiki engine with Git storage, multiple editors, and granular access controls. 📖

- **[MkDocs](https://github.com/mkdocs/mkdocs)** [![Stars](https://img.shields.io/github/stars/mkdocs/mkdocs?style=social&color=white)](https://github.com/mkdocs/mkdocs/stargazers)  
  **Fast and simple static site generator**, BSD-2-Clause licensed. **27,544+ Stars**. Python-based static documentation generator configured with simple YAML files. 📘

- **[Redoc](https://github.com/Redocly/redoc)** [![Stars](https://img.shields.io/github/stars/Redocly/redoc?style=social&color=white)](https://github.com/Redocly/redoc/stargazers)  
  **OpenAPI-generated API reference documentation**, MIT licensed. **25,942+ Stars**. Three-panel responsive OpenAPI renderer featuring code samples and customizable themes. 🔴

- **[VuePress](https://github.com/vuejs/vuepress)** [![Stars](https://img.shields.io/github/stars/vuejs/vuepress?style=social&color=white)](https://github.com/vuejs/vuepress/stargazers)  
  **Vue-powered static site generator**, MIT licensed. **22,726+ Stars**. Minimalist Vue-based static site generator optimized for technical documentation. 💚

- **[Material for MkDocs](https://github.com/squidfunk/mkdocs-material)** [![Stars](https://img.shields.io/github/stars/squidfunk/mkdocs-material?style=social&color=white)](https://github.com/squidfunk/mkdocs-material/stargazers)  
  **Material Design theme for MkDocs**, MIT licensed. **22,493+ Stars**. Feature-rich documentation theme with instant search, dark mode, code copy buttons, and accessibility. 🎨

- **[BookStack](https://github.com/BookStackApp/BookStack)** [![Stars](https://img.shields.io/github/stars/BookStackApp/BookStack?style=social&color=white)](https://github.com/BookStackApp/BookStack/stargazers)  
  **Simple, self-hosted documentation platform**, MIT licensed. **19,072+ Stars**. Organized into Books, Chapters, and Pages with Markdown and WYSIWYG support. 📚

- **[VitePress](https://github.com/vuejs/vitepress)** [![Stars](https://img.shields.io/github/stars/vuejs/vitepress?style=social&color=white)](https://github.com/vuejs/vitepress/stargazers)  
  **Vite & Vue-powered static site generator**, MIT licensed. **18,382+ Stars**. Modern, fast successor to VuePress powered by Vite and Vue 3. ⚡

- **[Scalar](https://github.com/scalar/scalar)** [![Stars](https://img.shields.io/github/stars/scalar/scalar?style=social&color=white)](https://github.com/scalar/scalar/stargazers)

- **[Documenso](https://github.com/documenso/documenso)** [![Stars](https://img.shields.io/github/stars/documenso/documenso?style=social&color=white)](https://github.com/documenso/documenso/stargazers)

Contributions are welcome! Follow these steps to submit new documentation platforms or open-source documentation software:

1. 🍴 **Fork** the repository.
2. 📝 **Add/edit** entries in `README.md` maintaining table/list structure and formatting.
3. 🔗 Include project title, official website/GitHub link, exact Stars_Count badge, license, and brief description.
4. 🚀 Submit a **Pull Request** with a descriptive summary of your changes.
